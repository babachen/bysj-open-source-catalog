## 开源规范

1. **一商品一仓库**；README **相关链接靠前** + 工坊截图/功能介绍。  
2. **可搬**：介绍 Markdown、架构说明、少量 samples、演示截图。  
3. **不搬**：完整业务源码、客户论文/任务书、真实密码、隐私信息。  
4. 完整版需求 → [www.bysj.site](https://www.bysj.site) 咨询。

## 和课题工坊的对应关系

```
www.bysj.site/blog  介绍文案  ──同步──>  catalog/blog/*.md
app.bysj.site 项目卡片  ──链接──>  GitHub showcase 仓库（30 个）
完整版需求  ──>  www.bysj.site 咨询
```
